# Emergent: The Last Signal

《Emergent》的基础 3D 可玩原型：玩家在低多边形森林和遗迹间寻找三块信号石，收集补给并返回篝火。狼群会根据距离、昼夜、饥饿、伤势、恐惧和营地守夜灯，在巡游、观察、追击与撤退之间切换。主角现为参照设定图制作的程序化低多边形角色，带有简单的迈步、摆臂和余烬冲击动作；还不是带骨骼动画的正式模型。这个版本优先验证探索和“玩家建造后，观察狼群如何改变行为”的体验；更大规模的建造与世界模拟尚未加入。

## 运行

用 Godot 4.7.2 打开 `project.godot`，点击运行。当前主场景是 `scenes/forest3d.tscn`。无需 Python 时也能玩，狼群使用本地决策。

- 鼠标移动：旋转第三人称视角；WASD / 方向键按镜头方向移动
- `Esc`：释放鼠标光标；左键点击游戏画面重新锁定
- `Space`：跳跃
- 鼠标右键 / `E`：拾取信号石、采集浆果、在营地消耗补给治疗；集齐三块石头后在营地通关
- 鼠标左键 / `Q`：释放余烬冲击，击退身边的狼，有 4 秒冷却
- `B`：在营地消耗两份补给，建造守夜灯，让狼群避开营地
- `F1`：显示或隐藏 AI 调试信息
- `L`：切换狼群是否使用本地 Laya 服务（默认关闭）
- `R`：结局后重新开始

玩家平时只看到狼的行为；需要检查决策时再按 F1。旧的 2D 玩法实验保留在 `scenes/main.tscn`，但不再作为默认入口。

森林地表、遗迹石材和信号石 HUD 图标使用项目内生成素材。主角外观参考图也保存在 `assets/characters/`，角色几何体由 `scripts/explorer_avatar.gd` 创建。源文件与生成提示词见 [`assets/README.md`](assets/README.md)；Godot 打开项目时会自动导入 PNG。

靠近可拾取物或篝火时，屏幕下方会显示对应操作；屏幕中心准星用于辨认视角方向。拾取与建造按距离触发。

## 接入 Laya

在另一个终端运行（首次推理会从 Hugging Face 下载模型，需要网络；服务和模型依赖占用较多磁盘与内存）：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r ai_server/requirements.txt
.venv/bin/python -m uvicorn ai_server.server:app --host 127.0.0.1 --port 8765
```

启动服务后在游戏中按 `L`，Godot 才开始每隔约 2.5 秒向服务发送一次狼群状态。有效响应会使 F1 调试信息显示 `Laya`；服务不可用、首次下载缓慢或请求失败时使用 `local` 决策。

模型只选择高层行动；移动、攻击范围、伤害、拾取与通关规则由 Godot 执行。目前使用未经本游戏微调的 `typed-decisions` 模型。它的输出可能违背玩家预期，概率也不能直接当作游戏行动的可靠效用。下一步应记录典型狼群局面与理想行动，比较模型和本地策略，再决定是否微调。

## 验证

在有 Godot 命令行的机器上执行：

```bash
godot --headless --path . --script res://tests/smoke.gd
```

测试覆盖三块信号石的收集、营地通关、守夜灯建造，以及狼群在白天、夜晚和受惊时的本地决策。Laya 模型本身仍需安装依赖并下载权重后另行验证。
