# Emergent: The Last Signal

《Emergent》的基础 3D 可玩原型：玩家在低多边形森林和遗迹间寻找三块信号石，收集补给并返回篝火。狼群会根据距离、昼夜、饥饿、伤势、恐惧和营地守夜灯，在巡游、观察、追击与撤退之间切换。营地同伴 Ari 会探索引路、采集补给、防卫或躲避，狼也会攻击她。主角和 Ari 都是程序化低多边形角色，已具备待机呼吸、行走、跳跃、伸手交互、冲击施放与受击反馈；还不是带骨骼动画的正式模型。这个版本优先验证探索和“玩家行动后，观察 AI 世界如何回应”的体验；更大规模的建造与世界模拟尚未加入。

## 运行

用 Godot 4.7.2 打开 `project.godot`，点击运行。当前主场景是 `scenes/forest3d.tscn`。无需 Python 时也能玩，狼群使用本地决策。

- 鼠标移动：旋转第三人称视角；WASD / 方向键按镜头方向移动
- 鼠标滚轮：在约 5.8–12.5 米范围内调整第三人称镜头距离
- `Esc`：释放鼠标光标；左键点击游戏画面重新锁定
- `Space`：跳跃
- 鼠标右键 / `E`：拾取信号石、采集浆果、在营地消耗补给治疗；集齐三块石头后在营地通关
- Ari 倒地时靠近并按 `E` / 右键：消耗一份补给救起她
- 鼠标左键 / `Q`：释放余烬冲击，击退身边的狼，并短暂扫描最近的信号石；有 4 秒冷却
- `B`：在营地消耗两份补给，建造守夜灯，让狼群避开营地
- `F1`：显示或隐藏 AI 调试信息
- `L`：切换 Ari 与狼群是否使用本地 Laya 服务（默认关闭）
- `R`：结局后重新开始

玩家移动加入短暂加减速，转向按实际速度平滑，跳跃带有短暂的离地宽容时间与落地前输入缓冲，按住空格不会自动连跳。主角和 Ari 的步态会跟随实际移动速度，落地时有轻微压缩反馈。第三人称镜头现在平滑跟随、贴近静态障碍时会收近，并根据移动速度轻微调整视野；镜头避障不再被 Ari 或狼的身体触发。玩家平时可以从 Ari 的移动、采集和狼的行为观察决策；需要检查具体行动与来源时再按 F1。Ari 的 HP 和当前行动显示在画面右上角；在营地时会缓慢恢复。旧的 2D 玩法实验保留在 `scenes/main.tscn`，但不再作为默认入口。

Ari 现在使用基于森林树干位置的轻量网格寻路，每隔约 0.6 秒更新路径，会绕开树干去采集、引路或回营。这不是完整的动态导航系统：其他会移动的角色不会被视为固定障碍。她不会自动拾取信号石，最后仍由玩家完成探索与回营。

冲击现在有扩散光环和 HUD 冷却条。狼已改用可复用的 [`scenes/wolf_avatar.tscn`](scenes/wolf_avatar.tscn) 模型场景：躯干、胸颈、头骨、长吻、四肢和尾巴都由低多边形连续网格构成，不再由方盒拼形；仅头顶的状态标记保留方形。移动时有交替步态与尾巴摆动，追击会压低头颈，攻击会前扑，眩晕时姿态会收缩；夜间重生会重置姿态。狼的眼睛与头顶灯继续显示意图：红色追击、金色观察、蓝色撤退、青色眩晕；颜色图例也在游戏 HUD 中。颜色只提示当前状态，狼的实际行动仍由 Godot 与可选 Laya 决策共同决定。

独立模型文件位于 [`assets/models/wolf_lowpoly.glb`](assets/models/wolf_lowpoly.glb)，可在 Godot 或支持 glTF 2.0 的工具中查看。GLB 是不带骨骼的静态模型；游戏使用原生狼场景的节点级程序化动作。调整 `scripts/wolf_avatar.gd` 后，可运行 `godot --headless --path . --script res://tools/export_wolf_model.gd` 重新导出 GLB。

每次冲击还会开启约 6 秒的信号扫描：HUD 按当前镜头方向显示最近未拾取信号石的前后左右方位和四舍五入到 5 米的距离。集齐三块后，扫描会指向营地。扫描与击退共用冷却，因此探索时使用也会暂时失去防身手段。

地图现在从营地空地分出三条可辨认的小径，分别通向石环遗址、符文门和孤立信标；狼的活动区有低矮的巢穴石和枯刺提示危险。小径是连续的弯曲地表网格，宽度有细微起伏，边缘渐隐并点缀草石；地面的矩形色块换成了贴地的苔藓斑。松树有锥度不同的树干、偏移的树冠和侧枝，继续使用项目内的苔藓树皮与针叶材质。林下还有蕨类、蘑菇、石群和碎石。主要路线与信号石附近保持开阔；新增大型道具目前是视觉装饰、没有碰撞体，Ari 的树干寻路与玩家移动规则不变。

主角和 Ari 现分别使用 [`scenes/explorer_avatar.tscn`](scenes/explorer_avatar.tscn) 与 [`scenes/ari_avatar.tscn`](scenes/ari_avatar.tscn)：修长的锥形衣裤和靴子替代盒装身体，增加五官、立领、翻领、腰带、皮包与信号坠饰。主角保留青色旅行外套、分片衣摆和层次短发；Ari 使用暖棕外套、围巾与游侠帽。动作由 `scripts/explorer_avatar.gd` 的四肢与头部节点驱动，包含抬脚步态、待机环顾、挎包和坠饰的轻微摆动，不需要骨骼动画。默认第三人称镜头已拉近、降低俯视角，仍可用滚轮拉远观察地图。独立静态模型在 `assets/models/explorer_lowpoly.glb` 与 `assets/models/ari_lowpoly.glb`；修改脚本后运行 `godot --headless --path . --script res://tools/export_character_models.gd` 可重新导出。主角外观参考图及素材提示词见 [`assets/README.md`](assets/README.md)。

树冠已由标准圆锥换成自定义多环网格：轮廓有错落的下沿与不对称鼓起，树高、树冠层数和侧枝数量因树而异，树干底部也增加了少量根部形态。整体仍属于低多边形风格，并非扫描级写实树木。

靠近可拾取物或篝火时，屏幕下方会显示对应操作；屏幕中心准星用于辨认视角方向。拾取与建造按距离触发。

## 接入 Laya

在另一个终端运行（首次推理会从 Hugging Face 下载模型，需要网络；服务和模型依赖占用较多磁盘与内存）：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r ai_server/requirements.txt
.venv/bin/python -m uvicorn ai_server.server:app --host 127.0.0.1 --port 8765
```

启动服务后在游戏中按 `L`，Godot 才开始向服务交替发送狼群和 Ari 的状态：每约 2.5 秒一次请求，每个智能体约 5 秒一次。有效响应会使 F1 调试信息显示 `Laya`；服务不可用、首次下载缓慢或请求失败时使用 `local` 决策。Ari 的危险行动仍受游戏规则约束，低血量时不会冒险防卫。

模型只选择高层行动；移动、攻击范围、伤害、拾取与通关规则由 Godot 执行。目前使用未经本游戏微调的 `typed-decisions` 模型。它的输出可能违背玩家预期，概率也不能直接当作游戏行动的可靠效用。下一步应记录典型 Ari 和狼群局面与理想行动，比较模型和本地策略，再决定是否微调。

## 验证

在有 Godot 命令行的机器上执行：

```bash
godot --headless --path . --script res://tests/smoke.gd
```

测试覆盖地图路径端点与树干净空、弯曲道路的渐隐网格、树干锥度与侧枝树冠、装饰碰撞安全、角色材质和部分动作姿态、玩家加减速、跳跃缓冲与镜头缩放、Ari 绕树寻路、采集、防卫、受伤和救助，狼的步态、前扑与夜间姿态重置，三块信号石的收集、营地通关、守夜灯建造，以及狼群在白天、夜晚和受惊时的本地决策。Laya 模型本身仍需安装依赖并下载权重后另行验证。
